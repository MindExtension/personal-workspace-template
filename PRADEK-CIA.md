# Pradėk čia

## Pirma sesija

- [ ] Patvirtinti, kas yra darbo erdvės savininkas ir kokia jos paskirtis.
- [ ] Užpildyti `DARBO-ERDVE.md`, neįrašant spėjimų.
- [ ] Patikrinti, kad iš šablono sukurtas repozitorijus yra privatus.
- [ ] Įjungti GitHub dviejų veiksnių autentifikavimą.
- [ ] Nuspręsti, kurios išorinės sistemos gali būti tik skaitomos, o kuriose leidžiami juodraščiai.
- [ ] Sukurti pirmą projektą pagal `sablonai/projektas.md`.
- [ ] Į `PROJEKTAI.md` įrašyti projekto nuorodą ir būseną.
- [ ] Į `BACKLOG.md` įrašyti pirmus konkrečius darbus.
- [ ] Paleisti `bash scripts/check-public-template.sh`.

## Saugus numatytasis režimas

- Laiškai yra tik juodraščiai, kol žmogus aiškiai paprašo siųsti.
- Kalendoriaus, Drive, CRM ar kitų sistemų įrašai nekeičiami be aiškaus leidimo.
- Originalūs dokumentai neperrašomi, analizė kuriama atskirai.
- Slaptažodžiai, raktai, asmens dokumentai ir pilnos komunikacijos kopijos į Git nekeliami.
- Nežinomas faktas žymimas `TIKRINTINA`, o ne papildomas spėjimu.

> patvirtintais faktais. Jokių išorinių pakeitimų nedaryk.
