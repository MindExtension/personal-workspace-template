# Projektai

Kiekvienas aktyvus projektas turi atskirą katalogą:

```text
projektai/
└── projekto-slug/
    ├── README.md
    ├── saltiniai.md
    └── rezultatai/
```

Projektą pradėti nukopijuojant `../sablonai/projektas.md` į jo `README.md`. Užduotis vis tiek laikyti
šaknies `BACKLOG.md`, o `PROJEKTAI.md` palikti projekto rodyklę.
