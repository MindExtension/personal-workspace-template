# Paruošimas

## GitHub

- [ ] Sukurti privatų repozitorijų per **Use this template**.
- [ ] Įjungti dviejų veiksnių autentifikavimą.
- [ ] Pakviesti tik tuos žmones, kuriems reikia prieigos.
- [ ] Patikrinti, kad pagrindinė šaka yra `main`.
- [ ] Jei dirba keli žmonės, įjungti Pull Request peržiūrą.

## DI darbo įrankis

- [ ] Naudoti paskyrą su aiškiai suprantamais duomenų nustatymais.
- [ ] Prijungti tik reikalingas programas ir paskyras.
- [ ] Skaitymo prieigą atskirti nuo rašymo prieigos.
- [ ] Išbandyti vieną skaitymo veiksmą ir vieną juodraštį be siuntimo.

## Pirmas projektas

- [ ] Nukopijuoti `sablonai/projektas.md` į `projektai/<slug>/README.md`.
- [ ] Įrašyti konkretų rezultatą ir patikros kriterijus.
- [ ] Įtraukti projektą į `PROJEKTAI.md`.
- [ ] Pirmus darbus įrašyti į `BACKLOG.md`.
